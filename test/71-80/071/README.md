# 071 云餐一楼 — Java 题解

原题面：[题目记录](../test71-80.md)，原记录标题 `072 云餐一楼`。实际题号以本文件标题为准。

## 解题思路

求严格递增长度。tails[len]保存长度len+1的递增子序列最小末尾；每个价格二分找第一个≥它的位置并替换，没有该位置就扩展长度。

## 正确性说明

更小的末尾为后续扩展提供不更差的机会，因此只保留最小末尾即可。二分位置之前的末尾都严格小于当前值，可以扩展为新长度；最终tails长度等于最长严格递增子序列长度。

## 复杂度

时间O(n log n)，空间O(n)。
