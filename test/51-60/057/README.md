# 057 楼梯有多少种爬法 — Java 题解

原题面：[本组题目](../test51-60.md)，查找题号 `057`。原记录保留不改。

## 解题思路

最后一步只可能跨1级或2级，所以f[n]=f[n-1]+f[n-2]，f[0]=f[1]=1。用两个滚动变量计算。

## 正确性说明

按最后一步大小将全部爬法分成两类，分别与到达n-1和n-2的爬法一一对应，两类互斥，数量直接相加。

## 复杂度

时间 O(n)，空间 O(1)。

## Java 实现

完整可提交代码见 [Main.java](Main.java)。每题独立编译，无包名，无第三方依赖，兼容 Java 8 及以上。
