## 解题思路

从外向内贪心寻找最短的相同非空前缀、后缀，找到后贡献2并递归处理剩余中间部分；找不到时剩余整体贡献1。直接比较字符，避免哈希碰撞。

## 正确性说明

最优分块的首尾块必相同。选择更短的匹配前后缀能够把其他匹配方案进一步细分，不减少中间可形成的块数，因此优先取最短匹配不会降低答案。剩余无匹配时只可作为一个中心块。

## 复杂度

时间 O(n²)，算法额外空间 O(1)。
