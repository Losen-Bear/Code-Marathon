## 021 金字塔挑战

### Description

小扣正在挑战金字塔，金字塔内共有N个房间，每个房间的编号从 0 到 N-1，每个房间可能包含不同的补血道具或者怪物，房间的影响通过一个数组 nums 表示：

* 正数表示该房间包含补血道具，增加对应数值的血量；
* 负数表示该房间包含怪物，减少对应数值的血量；
* 数值为 0 的房间对血量没有任何影响

小扣的初始血量为 1，并且血量没有上限。在挑战过程中，小扣原计划按照房间编号升序依次进入房间，但为了保证血量始终为正数，小扣可能需要调整访问的顺序。每次调整时，小扣只能将一个包含怪物（负数的房间）移到访问顺序的末尾。

请你计算出小扣最少需要进行多少次调整，才能顺利访问完所有房间。如果无论如何调整顺序都无法顺利访问完所有房间，返回 -1。

### Input

输入一个数组

数组每个值代表金字塔，每个房间可能包含不同的补血道具或者怪物，

* 正数表示该房间包含补血道具，增加对应数值的血量；
* 负数表示该房间包含怪物，减少对应数值的血量；
* 数值为 0 的房间对血量没有任何影响
* 1 <= nums.length <= 10^5
* -10^5 <= nums[i] <= 10^5

### Output

输出调整次数或无法调整则输出-1

### Sample Input 1

```text
100 100 100 -250 -60 -140 -50 -50 100 150
```

### Sample Output 1

```text
1
```

### Sample Input 2

```text
-200 -300 -400 0
```

### Sample Output 2

```text
-1
```

```java
            length++;
            current = current.next;

        for (int i = 0; i < length; i++) {
            array[i] = current.val;
            current = current.next;
        }
        return array;
    }

            current.next = new ListNode(value);
            current = current.next;
        }
```
