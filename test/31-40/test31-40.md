## 031 吃苹果

### Description

假设你在参加一个吃苹果比赛，你有n个苹果。比赛时，每一天，你可以在以下3种方案中选一种方式吃苹果：

1 吃掉一个苹果。

2 如果剩余苹果数 n 能被 2 整除，那么你可以吃掉 n/2 个苹果。

3 如果剩余苹果数 n 能被 3 整除，那么你可以吃掉 2*(n/3) 个苹果。

请问你吃掉所有苹果最少需要几天？

### Input

输入：10

解释：假设你总共需要吃掉10个苹果。

### Output

输出：4

解释：最少需要4天吃掉10个苹果。

第1天：吃 1 个苹果，剩余苹果数 10 - 1 = 9。
第2天：吃 6 个苹果，剩余苹果数 9 - 2*(9/3) = 9 - 6 = 3。 (9可以被3整除)
第3天：吃 2 个苹果，剩余苹果数 3 - 2*(3/3) = 3 - 2 = 1。
第4天：吃掉最后1个苹果，剩余苹果数 1 - 1 = 0。

### Sample Input 1

```text
10
```

### Sample Output 1

```text
4
```

## 034 找特定区间

### Description

给你一个整数数组 nums 以及两个整数 lower 和 upper 。求数组中，值位于范围 [lower, upper] （包含 lower 和 upper）之内的 区间和的个数 。

区间和 S(i, j) 表示在 nums 中，位置从 i 到 j 的元素之和，包含 i 和 j (i ≤ j)。

### Input

第一行为两个边界值，lower和upper。

* 1 <= nums.length <= 10^5
* -2^31<= nums[i] <= 2^31- 1
* -10^5<= lower <= upper <= 10^5

第二行为数组nums的长度n。
接下来为n个数为数组nums。

### Output

输入：lower = -2, upper = 2, n=3, nums = [-2,5,-1]。
输出：3
解释：存在三个区间：[0,0]、[2,2] 和 [0,2] ，对应的区间和分别是：-2 、-1 、2 。

### Sample Input 1

```text
-2 2
3
-2 5 -1
```

### Sample Output 1

```text
3
```

### Hint

### Description

给定一个非负整数 k，存在一个无限长的台阶序列，其中最低的一层编号为 0。Alice 初始时位于台阶 1，并且她的跳跃能力（记为 jump）初始值为 0。Alice 的目标是到达第 k 级台阶。在每一次操作中，Alice 可以执行以下两种操作之一：

* 向下走一级到 i - 1，但此操作不能连续使用，并且当 Alice 在第 0 级台阶时不能使用。
* 向上跳至 i + 2 * jump 级台阶，然后将她的跳跃能力 jump 增加 1。

非负整数 k，表示目标台阶数
(0≤k≤10^9)

## 039 特殊的回文

### Description

存在一个字符串 text 。你可以把它分成j个子字符串（subtext1，subtext2，...， subtextj），要求满足：

* subtexti 是**非空**字符串
* 所有子字符串的连接等于 text ( 即 subtext1+ subtext2+ ... + subtextj== text )
* 对于所有 i 的有效值( 即 1 ≤ i ≤ j ) ， subtexti == subtextj - i + 1 均成立

返回j的最大值。

### Input

输入字符串text
1 ≤ text.length≤1000
text 仅由小写英文字符组成

### Output

输出 j 的最大值

### Sample Input 1

```text
ghiabcdefhelloadamhelloabcdefghi
```

### Sample Output 1

```text
7
解释：ghi+abcdef+hello+adam+hello+abcdef+ghi = ghiabcdefhelloadamhelloabcdefghi
```

### Sample Input 2

```text
merchant
```

### Sample Output 2

```text
1
```

### Hint

```java
public static void main(String[] args) {
```
