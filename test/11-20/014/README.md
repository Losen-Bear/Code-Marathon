# 014 异或 — Java 题解

原题面：[本组题目](../test11-20.md)，查找题号 `014`。原记录保留不改。

## 解题思路

1到N的异或以4为周期，N mod 4分别为0、1、2、3时答案为N、1、N+1、0。用long处理10^18。

## 正确性说明

每组连续四数4t、4t+1、4t+2、4t+3的异或为0，将完整组抵消后只剩末尾余数对应的几项。

## 复杂度

时间 O(1)，空间 O(1)。

## Java 实现

完整可提交代码见 [Main.java](Main.java)。每题独立编译，无包名，无第三方依赖，兼容 Java 8 及以上。

```sh
javac -encoding UTF-8 Main.java
java Main
```
