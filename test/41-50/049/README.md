# 049 工具怎么下 — Java 题解

原题面：[本组题目](../test41-50.md)，查找题号 `049`。原记录保留不改。

## 解题思路

所有翻倍操作都可移到下载操作之前，不会降低已下载数。枚举翻倍次数t，速度为2^t，下载至少需要ceil(n/2^t)分钟，最小化t+ceil(n/2^t)。

## 正确性说明

把某次翻倍向前与相邻下载交换，使那次下载速度更快，其余操作不变，收益不减。反复交换后总是先翻倍再下载，枚举t就覆盖最优方案。

## 复杂度

时间 O(log n)，空间 O(1)。
