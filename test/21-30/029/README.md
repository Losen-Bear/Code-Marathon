# 029 分治排序 — Java 题解

原题面：[本组题目](../test21-30.md)，查找题号 `029`。原记录保留不改。

## 解题思路

归并排序。递归排序左右半段，再用两个指针合并到临时数组，拷贝回原区间。

## 正确性说明

单元素区间天然有序。若两半已排序，每次取两半当前较小值就能得到全局下一小值，合并结果有序；归纳得到完整数组有序。

## 复杂度

时间 O(n log n)，空间 O(n)。

## 题面与格式说明

输入没有数组长度，第一项也是数组元素。
