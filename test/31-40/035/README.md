# 035 购买两本书 — Java 题解

原题面：[本组题目](../test31-40.md)，查找题号 `035`。原记录保留不改。

## 解题思路

一次扫描找到最小和次小书价，若其和不超过money则减去，否则原样返回money。相同价格的不同书可以同时购买。

## 正确性说明

任意两本书的价格和都不小于最小的两项之和，所以这对使剩余资金最大；若这对都买不起，则任何一对都买不起。

## 复杂度

时间 O(n)，算法额外空间 O(1)。
