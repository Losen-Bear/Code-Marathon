# 088 完美排列 — Java 题解

原题面：[题目记录](../test81-90.md)，原记录标题 `078 完美排列`。实际题号以本文件标题为准。

## 解题思路

状态压缩DP。mask记录已经放入排列的数字，下一位置i=bitCount(mask)+1。对每个未使用x，若i整除x或x整除i，就将当前计数加入新mask。

## 正确性说明

状态转移只添加满足当前位置规则且尚未使用的数字，所以每条状态链对应合法排列。任意合法排列按顺序添加都能形成一条唯一链，计数完整且不重复。

## 复杂度

时间O(N·2^N)，空间O(2^N)。
