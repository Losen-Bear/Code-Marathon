# 095 买到所有玩具 — Java 题解

原题面：[题目记录](../test91-100.md)，原记录标题 `095 买到所有玩具`。实际题号以本文件标题为准。

## 解题思路

按价格降序每三件分组，支付前两件，第三件免费。余下不足三件全部付费。实现时升序排序再从末尾扫描，每第三件跳过。

## 正确性说明

每个赠品必须配两件不更便宜的付费品。按降序对最贵的三件分组时，前两件必需付费或能替换对应更贵付费品；取第三件免费可获得最大的当前合法折扣。重复交换可将最优方案整理成相邻三件分组。

## 复杂度

时间O(n log n)，空间O(n)。
