## 072 云餐一楼

### Description

你在云餐一楼吃饭。

众所周知，云餐一楼的窗口比星南二楼多得多，有 n(n ≤ 100,000) 个窗口，它们是按顺序排成一排的。

为了简化题目，每个窗口只卖一种餐，且第 i 个窗口的餐的售价为 ai(ai ≤ 1,000,000,000) 元。

你从第一个窗口开始，依次走遍每一个窗口，直到走到最后一个窗口。在此过程中你不会回头，即你不会在买了某个窗口的餐之后，返回去买任何的餐。

你有一个非常奇怪的癖好，你希望自己每次买的餐比上一次买的餐要更贵。即如果你买了第 i 个窗口的餐，你后续将不能再买任何价格小于或等于 ai 的餐。

对每一个窗口，（如果你有得选，）你可以选择买或不买该窗口的餐。

求你最多可以买多少种餐。

### Input

第一行输入一个正整数 n，表示云餐一楼有多少个窗口。

接下来 n 行，每行一个正整数 ai，表示第 i 个窗口的餐的售价。

测试用例保证输入都是正整数。

### Output

输出一个整数，表示你最多可以买多少种餐。

### Sample Input 1

```text
6
1
1
4
5
1
4
```

### Sample Output 1

```text
3
```

### Sample Input 2

```text
6
1
9
1
9
8
10
```

### Sample Output 2

```text
3
```

## 076 最长线段

### Description

给定一个m*n的二进制矩阵mat，返回矩阵中最长的连续的线段。

这条线段可以是水平的、垂直的、对角线的或者反对角线的。

### Input

第一行矩阵行数m和列数n

接下来为一个m行n列矩阵，矩阵中的每个元素为0或1

* 1 <= m, n <= 10^4
* mat[i][j] 不是 0 就是 1

### Output

输出矩阵中最长1线段的长度

### Sample Input 1

```text
3 4
1 1 1 1
0 1 1 0
0 0 0 1
```

### Sample Output 1

```text
4
```

### Hint

```java
public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int m = sc.nextInt();
    int n = sc.nextInt();
    int[][] grid = new int[m][n];
    for(int i=0;i<m;i++) {
        for(int j=0;j<n;j++) {
            grid[i][j] = sc.nextInt();
        }
    }
}
```

2


```text

```
