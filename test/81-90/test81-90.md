## 071 最长字符串

### Description

给定一个字符串数组 arr，现在要从 arr 中选出一部分字符串拼接成一个新的字符串 s，要求 s 中的每一个字符都只出现过一次。求字符串 s 能达到的最长长度。

### Input

第一行输入字符串数组 arr 的元素个数 k。
接下来 k 行分别输入 arr 中的 k 个字符串。

### Output

输出拼接的字符串的最长长度。

### Sample Input 1

```text
4
cha
r
act
ers
```

### Sample Output 1

```text
6
解释：拼接的最长字符串为 "chaers" 和 "acters"。
```

### Description

不同障碍物的高度整数数组 heights 表示。另有一些砖块 bricks 和梯子 ladders。
你从障碍物 0 开始旅程，不断翻越障碍物，期间可能会用到砖块或梯子。

如果当前障碍物的高度大于或等于下一建筑物的高度，则不需要梯子或砖块
如果当前障碍物的高度小于下一个建筑的高度，您可以使用一架梯子或 (h[i+1] - h[i]) 个砖块

## 073 货物运输

### Description

你驾驶一辆面包车行驶在一个有n个仓库的路线上。仓库的距离由近到远编号为1到n，部分仓库有一批货物需要运输到后面z的仓库，你只能沿着编号递增的方向驾驶。
每批货物从仓库i出发，前往仓库j，运输获得的额外奖励为k，每一批货物能够获得的利润为 j-i+k，同一时间最多只能运输一批货物。

### Input

第1行输入仓库个数n和货物数量m；
接下来的m行输入m批货物信息i, j, k。

### Output

一个正整数，代表最大盈利。

### Sample Input 1

```text
5 2
2 5 4
1 5 1
```

### Sample Output 1

```text
7
```

### Sample Input 2

```text
20 6
1 6 1
3 10 2
10 12 3
11 12 2
12 15 2
13 18 1
```

### Sample Output 2

```text
20
```

### Hint

1 ≤ n ≤ 10^5
1 ≤ m ≤ 3 * 10^4
1 ≤ i < j ≤ n
1 ≤ k ≤ 10^5

```cpp
#include <bits/stdc++.h>

using namespace std;

long long PO154(int n, vector<vector<int>>& goods)
{

}

{
    int n, m;
    vector<vector<int>> goods;
    cin >> n >> m;

        int i, j, k;

        good.push_back(j);
        good.push_back(k);
        goods.push_back(good);
    }
    cout << PO154(n, goods) << endl;
    return 0;
}
```

## 074 拟合

### Description

小明有两个一模一样的数列玩具！他很开心的把玩，不过不小心没拿稳将数列摔坏了！
现在他手上的两个数列分别为A和B，长度分别为n和m。小明很想再次让这两个数列变得一样。他现在能做两种操作，
操作一是将一个选定数列中的某一个数a改成数b，这会花费|b-a|的时间，操作二是选择一个数列中某个数a，
将它从数列中丢掉，花费|a|的时间。小明想知道，他最少能以多少时间将这两个数列变得再次相同！

### Input

第一行两个空格隔开的正整数n和m，分别表示数列A和B的长度。
接下来一行n个整数，分别为A1 A2...An
接下来一行m个整数，分别为B1 B2...Bm
对于所有数据，1≤n,m≤2000， |Ai|,|Bi|≤10000

### Output

输出一行一个整数，表示最少花费时间，来使得两个数列相同。

### Sample Input 1

```text
1 1
-100
100
```

### Sample Output 1

```text
200
```

### Hint

```cpp
int main()
{
    int n, m;
    cin >> n >> m;
    vector<int> a(n), b(m);
    for (int i = 0; i < n; ++i){
        cin >> a[i];
    }
    for (int i = 0; i < m; ++i) {
        cin >> b[i];
    }
    return 0;
}
```

## 090 采矿

### Description

矿山里有不同的矿物，采出一种矿物需要一定的时间，每一种矿物有固定的价值。给你一些时间，在这些时间里，你可以自由选择采什么矿物，但是你需要让采出的矿物总价值最大。

### Input

第一行输入时间n和矿物种类数目m；
接下来m行输入特定矿物的采矿时间c和这种矿物的价值v。

### Output

一个正整数，矿物的最大总价值。

### Sample Input 1

```text
70 3
71 100
69 1
1 2
```

### Sample Output 1

```text
3
```

### Hint

1 ≤ n ≤ 1000
1 ≤ m ≤ 100
1 ≤ c ≤ 100
1 ≤ v ≤ 100

```cpp
#include <bits/stdc++.h>

using namespace std;

int PO151(vector<int>& cost, vector<int>& value, int n)
{

}
int main()
{
    int n, m;
    vector<int> c, v;
    cin >> n >> m;
    for(int i = 0;i < m;i ++)
    {
        int cost, value;
        cin >> cost >> value;
        c.push_back(cost);
        v.push_back(value);
    }
    cout << PO151(c, v, n) << endl;
    return 0;
}
```
