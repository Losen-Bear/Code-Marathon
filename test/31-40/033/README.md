# 033 谁是多数元素 — Java 题解

原题面：[本组题目](../test31-40.md)，查找题号 `033`。原记录保留不改。

## 解题思路

Boyer-Moore多数投票。计数为0时更换候选；相同元素加1，不同元素减1。最终输出候选。

## 正确性说明

每次抵消一对不同元素不会改变多数元素必然超过剩余其他元素总数的性质。题目保证多数元素存在，最终未被抵消的候选只能是它。

## 复杂度

时间 O(n)，算法额外空间 O(1)。
