# 062 寻找反向对 — Java 题解

原题面：[题目记录](../test61-70.md)，原记录标题 `062 寻找反向对`。实际题号以本文件标题为准。

## 解题思路

把最大数i插入一个i-1元素的排列，可新增0到i-1个逆序对。dp[i][j]=Σdp[i-1][j-t]，用滑动窗口求和，将每层从O(k·i)降为O(k)。

## 正确性说明

插入位置与新增逆序对数一一对应，且删除最大数能唯一还原原排列，所以递推无遗漏和重复。滚动窗口恰好维护规定范围内的和。

## 复杂度

时间O(nk)，空间O(k)。
