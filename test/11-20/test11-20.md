## 012 最小全覆盖子串

### Description

所谓A子串全覆盖B就是：A子串中每个字符出现的频率大于等于B中每个字符出现的频率。

### Input

输入一个字符串A和一个字符串B，如：

```text

```

### Output

返回的子串满足两个条件：

1. 该子串全覆盖B
2. 长度尽可能小

比如上面输入的答案：aboa

### Sample Input 1

```text

```

### Sample Output 1

```text

```

### Hint

1. 测试用例中满足条件的子串是唯一的，不用考虑多种情况
2. A字符串的长度只有大于等于B字符串的长度时才可能有解（特殊情况需要处理）

## 020 最大购书开销

### Description

给你一个下标从 0 开始大小为m×n 的整数矩阵 prices ，表示 m 个不同书店里m×n本不同的书。每个书店有n本书，第i个书店的第j本书的价格为 prices[i][j] 。除此以外，第i个书店的书已经按照价格非递增排好序了，也就是说对于所有0≤j<n-1都有 prices[i][j] >= prices[i][j + 1] 。

每一天，你可以在一个书店里购买一本书。具体来说，在第d天，你可以：

* 选择书店i。
* 购买数组中最右边的书，开销为 prices[i][j] *d。换句话说，选择该书店中还没购买过的书中最大的下标，并且花费 prices[i][j]* d 去购买。

注意，所有书都视为不同的书。比方说如果你已经从书店 1 购买了书 0，你还可以在别的书店里购买其他书店的书 0。

请你返回购买所有m×n本书需要的最大开销。

### Input

输入一个矩阵，每一行代表一个书店，每一行的值代表各本书的价格。

### Output

返回购买所有m×n本书需要的最大开销。

### Sample Input 1

```text
8 5 2
6 4 1
9 7 3
```

### Sample Output 1

```text
285
```

### Sample Input 2

```text
10 8 6 4 2
9 7 5 3 2
```

### Sample Output 2

```text

```
