# 054 解平铺数 — Java 题解

原题面：[本组题目](../test51-60.md)，查找题号 `054`。原记录保留不改。

## 解题思路

设f[n]为2×n完整铺法数，g[n]为末列缺一个指定角格的铺法数。f[n]=f[n-1]+f[n-2]+2g[n-1]，g[n]=g[n-1]+f[n-2]。消去g得到f[n]=2f[n-1]+f[n-3]，初值1、1、2。

## 正确性说明

末端可以竖放骨牌、横放两骨牌，或由两种对称缺角状态补L形砖，分别对应完整状态的三项。缺角状态由延伸缺角或从更短完整墙面创建得到。按末端形状分解互斥且完整，递推正确。

## 复杂度

时间 O(n)，空间 O(1)。
