# 069 无聊的小明 — Java 题解

原题面：[题目记录](../test61-70.md)，原记录标题 `069 无聊的小明`。实际题号以本文件标题为准。

## 解题思路

持续计算各位平方和，用HashSet记录已经出现的数。遇到1输出yes，重复出现同一数则进入循环，输出no。

## 正确性说明

每个数的后继唯一，重复状态后后续序列也重复，不可能再新到达1。32位整数一次变化后至多810，有限状态必然到达1或重复。

## 复杂度

本题数值范围内时间、空间O(1)。

## 题面与格式说明

0的平方和仍是0，因此输出no。

## Java 实现

独立代码：[Main.java](Main.java)。兼容Java 8及以上，无包名、无第三方依赖。

```sh
javac -encoding UTF-8 Main.java
java Main
```
