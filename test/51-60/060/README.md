# 060 找数游戏 — Java 题解

原题面：[本组题目](../test51-60.md)，查找题号 `060`。原记录保留不改。

## 解题思路

按模3余数做DP。dp[r]为已处理元素中和余数为r的最大可达子集和，初始仅dp[0]=0。每个元素从旧数组转移，选择或跳过它。

## 正确性说明

每个子集要么不含当前元素，要么由旧子集加入当前元素形成，复制旧DP再转移正好覆盖两类且每个元素最多选一次。最终dp[0]就是最大可整除3的和。

## 复杂度

时间 O(n)，算法额外空间 O(1)。
