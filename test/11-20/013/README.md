# 013 这货不是括号匹配 — Java 题解

原题面：[本组题目](../test11-20.md)，查找题号 `013`。原记录保留不改。

## 解题思路

递归解析括号表达式。同一分支内的连接长度相加，遇到|取各分支最大值，遇到括号递归求内部最长长度。

## 正确性说明

串联可以分别选择各部分最长匹配，所以长度相加；或运算只能选一个分支，所以取最大。按照语法树递归计算得到根表达式的最长匹配长度。

## 复杂度

时间 O(n)，空间 O(n)。
