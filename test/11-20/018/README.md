# 018 关于多项式 — Java 题解

原题面：[本组题目](../test11-20.md)，查找题号 `018`。原记录保留不改。

## 解题思路

用导数3px²+2qx+r的两个零点将[-100,100]分成三个单调区间。在每个区间用二分查找一个实根，按区间顺序输出。

## 正确性说明

三个不同实根保证导数有两个临界点，根分别位于三个单调区间。单调区间内至多一个根，二分根据函数符号保留含根区间，固定迭代次数得到足够的两位小数精度。

## 复杂度

时间 O(迭代次数)，空间 O(1)。

## 题面与格式说明

不依赖“相邻根距离至少1”的额外假设；支持间距小于1的三根。
