# 064 智能翻译 — Java 题解

原题面：[题目记录](../test61-70.md)，原记录标题 `064 智能翻译`。实际题号以本文件标题为准。

## 解题思路

把整数按三位一组分为Billion、Million、Thousand及个位组。每组按百位、十位、个位转换，忽略值为0的中间组，整体0输出Zero。

## 正确性说明

三位分组是十进制位权的唯一分解，组内百位和不足百部分的词法映射唯一，按高位到低位拼接即所需英文形式。
