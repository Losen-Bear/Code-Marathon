# 056 寻找“理想数对” — Java 题解

原题面：[本组题目](../test51-60.md)，查找题号 `056`。原记录保留不改。

## 解题思路

归并排序统计。左右半段分别有序后，对左侧每个值用单调指针找到右侧满足a[i]>2a[j]的前缀长度，累加，再普通合并。比较时用long乘2。

## 正确性说明

递归统计同半区理想数对，合并统计跨半区数对；排序后右侧满足条件的值构成前缀，指针不会回退，计数精确。两类互斥覆盖全部i<j。

## 复杂度

时间 O(n log n)，空间 O(n)。
