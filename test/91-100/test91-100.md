## 091 智慧码头

### Description

现在有一个智慧码头，配备有无人运输车，现在假定：

1. 码头是一个N*N网格，每个网格内有0-2件货物，记为package[i][j] (0<=i,j<N)。
2. 无人运输车A从网格左上角[0,0]进入，从右下角[N-1,N-1]驶出，只允许向下或向右运行，将沿途货物运出网格。
   无人运输车B从网格右下角[N-1,N-1]进入，从左上角[0,0]驶出，只允许向上或向左运行，将沿途货物运出网格。
3. 由于流水线要求，无人运输车从每个网格内最多提取一件货物。

请设计无人运输车A，B的运行路线，返回二者运输货物总和的最大值。

### Input

第一行码头的长度N
接下来N行是每个网格存放的货物数量

输入各数据范围：
0<N<=30
0<package[i][j]<=2
0<=i,j<N

### Output

二者运输货物总和的最大值

### Sample Input 1

```text
3
1 2 1
1 0 1
1 2 1
```

### Sample Output 1

```text
8
```

### Hint

```java
public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int n = sc.nextInt();
    int[][] grid = new int[n][n];
    for(int i=0;i<n;i++) {
        for(int j=0;j<n;j++) {
            grid[i][j] = sc.nextInt();
        }
    }
}
```

## 092 计算数组积分

### Description

玩一个数字游戏，给你一个大小为 2 *n 的正整数数组nums。你必须对这个数组执行 n 次操作。在第 i 次操作时（操作编号从 1 开始），你需要：1、选择两个元素 x 和 y 。2、获得积分 i* gcd(x, y) 。3、将 x 和 y 从 nums 中删除。

请你返回 n 次操作后你能获得的最大积分和。

函数 gcd(x, y) 是 x 和 y 的最大公约数。

### Input

输入一个大小为 2 * n 的正整数数组nums，其中1 <= n <= 7。

### Output

输出每次操作后所得积分总和的最大值

### Sample Input 1

```text
[1,2,3,4,5,6]
```

### Sample Output 1

```text
14
解释：最优操作是：(1 * gcd(1, 5)) + (2 * gcd(2, 4)) + (3 * gcd(3, 6)) = 1 + 4 + 9 = 14
```

## 099 贪吃鬼

### Description

给你一车食品，它由3*n个不同数量的食物堆组成，现在你和你的朋友们需要按照如下规则来分披萨：
你挑选任意一堆食物。
小A将会挑选你所选择的食物堆的左边一堆。
小B将会挑选你所选择的食物堆的右边一堆。
重复上述过程直到没有食物剩下。
每一堆食物的数量由循环数组表示。 （注意数组是循环的，即你吃了第1堆，小A会去吃第n堆）
请你返回你可以吃到的食物数量总和的最大值。

### Input

输入食物堆数组slices，数组中每个元素代表每个食物堆的数量，元素之间用","隔开。
1≤slices.length≤10
slices.length % 3 == 0
0≤slices[i]≤1000

### Output

输出你可以吃到的食物数量总和的最大值。

### Sample Input 1

```text
1,2,3,4,5,6
```

### Sample Output 1

```text
10
解释：选择数量为 4 的堆，小A和小B分别挑选数量为 3 和 5 的堆。然后你选择数量为 6 的堆，小A和小B分别挑选数量为 2 和 1 的堆。你吃的食物总数量为 4 + 6 = 10 。
```

### Sample Input 2

```text
8,9,8,6,1,1
```

### Sample Output 2

```text
16
解释：两轮都选大小为 8 的堆。如果你选择数量为 9 的堆，你的朋友们就会选择数量为 8 的堆，这种情况下你的总和不是最大的。
```

### Hint
