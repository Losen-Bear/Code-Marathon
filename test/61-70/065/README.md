# 065 逆序对的总数 — Java 题解

原题面：[题目记录](../test61-70.md)，原记录标题 `065 逆序对的总数`。实际题号以本文件标题为准。

## 解题思路

归并排序计数。合并两段时，若右段当前值小于左段当前值，它与左段尚未合并的所有元素构成逆序对，增加mid-i。

## 正确性说明

递归统计各半段内部，合并统计跨半段。左半段有序，右值小于当前左值时剩余左值都更大，精确增加这些数对。三类互斥覆盖全部逆序对。

## 复杂度

时间O(n log n)，空间O(n)，计数使用long。
