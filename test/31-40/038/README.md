# 038 寻找方案 — Java 题解

原题面：[本组题目](../test31-40.md)，查找题号 `038`。原记录保留不改。

## 解题思路

上跳j次后不考虑下行时所在台阶为2^j。若要到k则必须下行d=2^j-k次。下行不能连续，可以从j次上跳的前后共j+1个空隙中选d个，贡献组合数C(j+1,d)。累加所有满足0≤d≤j+1的j。

## 正确性说明

上跳位移是1+1+2+…+2^(j-1)=2^j，所以下行次数唯一确定。每个空隙至多一个下行，合法方案与选空隙一一对应；初始台阶为1且后续累计上跳增长足够，因此这些选择不会从0下行。不同j对应不同操作序列，直接求和。

## 复杂度

时间 O(log²(k+2))，空间 O(1)。

## 题面与格式说明

题面“2 * jump”及样例中的20、21是指数排版丢失；按样例应为2^jump。若按乘法理解，样例不成立。
